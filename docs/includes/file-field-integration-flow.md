The **File** field takes a [file reference](/flow/user-guides/about-flow/#files) produced by an earlier node, such as a file downloaded by an [*HTTP request* action node](/flow/user-guides/configure-action-node/#configure-an-http-request-action-node) or uploaded to the [*Webhook* trigger](/flow/user-guides/add-trigger/#add-a-webhook-trigger), not literal text content. The field holds one reference and nothing else. Text around the reference or a second reference shows an inline error, because the run would fail. In this field, picking an entry from the **Files** group of the variable suggestions inserts the file itself, not its metadata.
