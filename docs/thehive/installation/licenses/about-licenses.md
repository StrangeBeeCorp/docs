# TheHive Plans and Licenses

TheHive is available as a free Community Edition and as paid plans to meet various organizational needs, from essential features for getting started to comprehensive capabilities for large-scale incident response.

!!! info "Cortex"
    Since Cortex is a fully open-source project, you don't need a license to use it.

!!! tip "Platinum trial"
    <!-- md:version 5.3 --> Installing TheHive On-prem or using TheHive Cloud Platform for the first time includes a 14-day trial of the Platinum plan. After this trial period, TheHive transitions to read-only mode, requiring a valid license for all users for continued full functionality.

!!! warning "Upgrading TheHive Community Edition"
    If you're upgrading to TheHive version 5.3 or later from TheHive 5.x Community Edition, be sure to [request a license for TheHive Community Edition on the StrangeBee license portal](../../installation/licenses/request-a-community-license.md). Without this registration, your interface is limited to read-only mode.

## Plans and pricing

| Plan    | Supported solution       | Purpose | Pricing |
| :---------- | :---------------------      |  :---------------------      | :---------------------      |
| TheHive Community Edition   |  On-prem                    | Free, self-hosted version of TheHive for non-commercial use, such as learning, academic research, and personal home labs. Includes core incident response features. | Free—requires [requesting a license](request-a-community-license.md) |
| Gold       |  On-prem                    | Designed for internal response teams requiring enhanced case management lifecycles and organizational integrations. | Paid—requires [contacting the StrangeBee team](https://strangebee.com/contact-strangebee/){target=_blank}|
| Platinum    |  On-prem and Cloud Platform | Ideal for large teams needing extensive server connections, clustering, and dedicated continuous support for mission-critical, large-scale incident response. | Paid—requires [contacting the StrangeBee team](https://strangebee.com/contact-strangebee/){target=_blank} |
| ONE <!-- md:version 6.0 -->  |  On-prem | The most complete offering, including all Platinum capabilities plus [TheHive Flow](../../../flow/user-guides/about-flow.md) automation. | Paid—requires [contacting the StrangeBee team](https://strangebee.com/contact-strangebee/){target=_blank} |

Every plan, and TheHive Community Edition, requires [activating a license](license.md).

Check the pricing details and the list of features available for each plan on the [StrangeBee pricing page](https://strangebee.com/thehive-pricing/){target=_blank}.

## Terms and quotas

Each license includes validation and expiration dates.

Each plan has specific quotas for:

* Number of users: Only unlocked user accounts of type Normal with at least one licensed permission count toward the license limit. Service accounts and Normal accounts with no licensed permissions, such as [Read-Only or Admin](../../administration/profiles/about-profiles.md#predefined-profiles), don't. External accounts consume license seats but are unlimited.
* Number of organizations: Only unlocked organizations count toward the license limit.
* Number of instances
* Number of Cortex servers
* Number of Malware Information Sharing Platform (MISP) servers
